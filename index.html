Lock Screen Widget (iOS)

Add a cleaning progress widget to your iPhone lock screen using the Shortcuts app:

1. Open the Shortcuts app on iPhone
2. Tap + → search Safari → "Open URL"
3. Set URL to: https://scottysadler-pixel.github.io/mindi-cleaning/
4. Save as "Open Mindi". Long-press lock screen → Add Widgets → pick Shortcuts widget → choose "Open Mindi"

Now you can jump straight into the app from your lock screen with one tap.
